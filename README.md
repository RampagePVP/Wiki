# Rampage PvP Wiki

Rampage PvP'nin resmi oyuncu rehberine hoş geldin. Burada sunucudaki sistemlerin nasıl çalıştığını, komutları, setleri, binekleri, etkinlikleri ve ekonomiyi bulabilirsin.

## Bölümler

| Bölüm            | İçinde ne var                                                                              |
| ---------------- | ------------------------------------------------------------------------------------------ |
| **Başlarken**    | İlk adımlar, safe alan, moongate, oyuncu komutları, kurallar ve safe alan taşları          |
| **Karakter**     | Sınıflar ve statlar, fame, rütbe, görevler                                                 |
| **PvP ve Savaş** | Setler, robeler, silahlar, silah bonusları, kalkan ve savunma, büyüler, upgrade, potionlar |
| **Binekler**     | Binek sistemi, yetenekli binekler, geliştirme, taming, random spawn, golemler              |
| **Guild ve PvP** | Guild sistemi, guild savaşları, PvP ligi ve kral, sıralamalar, düello, PvP alanları        |
| **Etkinlikler**  | Etkinlik takvimi, 1vs1 turnuva, CTF, Quest, Deathmatch ve diğer etkinlikler                |
| **PvM**          | Dungeonlar, solo dungeon, zindan, bosslar, set elde etme, canavarlar                       |
| **Ekonomi**      | Gold ve satıcılar, pazar, evler, depo, hazine, kumar                                       |

{% hint style="info" %}
Sunucu sürekli güncelleniyor. Bir bilgi oyundakiyle uyuşmuyorsa ya da bir sistemi anlamadıysan oyunda **Help** menüsünden yetkililere ulaşabilirsin.
{% endhint %}
