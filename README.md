# Rampage PvP Wiki

Rampage PvP'nin resmi oyuncu rehberine hoş geldin. Aradığın konu hangi bölümdeyse soldaki menüden o bölümü aç.

## Bölümler

| Bölüm            | İçinde ne var                                                                                     |
| ---------------- | ------------------------------------------------------------------------------------------------- |
| **Başlarken**    | İlk adımlar, safe alan, moongate, oyuncu komutları, kurallar                                      |
| **Karakter**     | Sınıflar ve statlar, fame ve rütbe, büyüler, potionlar ve iyileşme                                |
| **Eşyalar**      | Setler, robeler, silahlar, silah bonusları, kalkanlar, upgrade, safe alan taşları                 |
| **Binekler**     | Binek sistemi, yetenekli binekler, geliştirme, taming, random spawn, golemler                     |
| **Sistemler**    | Gold ve satıcılar, eşya deposu, pazar, evler, zanaat, hazine, görevler, balık ve maden, kumar     |
| **Guild ve PvP** | Guild, köyler, guild savaşları, takım savaşı, PvP ligi ve kral, sıralamalar, PvP alanları, düello |
| **Etkinlikler**  | Etkinlik takvimi, PvP turnuvası, CTF, Quest, Deathmatch, Köprü Savaşı ve mini etkinlikler         |
| **PvM**          | Dungeonlar, parti zindanı, solo dungeon, bosslar, set elde etme, canavarlar                       |

{% hint style="info" %}
Sunucu sürekli güncelleniyor. Bir bilgi oyundakiyle uyuşmuyorsa ya da bir sistemi anlamadıysan oyunda **Help** menüsünden yetkililere ulaşabilirsin.
{% endhint %}
