# Oyuncu Komutları

Rampage PvP'de oyuncuların kullanabildiği bütün nokta (`.`) komutları aşağıda konularına göre listelenmiştir. Komutlar sohbet satırına yazılır, örneğin `.online`. Aynı işi yapan komutlar aynı satırda gösterilmiştir.

{% hint style="info" %}
Paperdoll'daki **Help** butonuyla açılan yardım menüsündeki **Komutlar** düğmesi de kısa bir komut listesi gösterir.
{% endhint %}

## Hesap ve karakter

| Komut           | Açıklama                                                                                                                                                                                   |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `.sifre`        | Şifre değiştirme menüsü (4-15 karakter, sadece İngilizce harf ve rakam, boşluksuz)                                                                                                         |
| `.pin`          | Pin girişi, pin değiştirme, pin sistemini kapatma ya da unutulan pini yenileme                                                                                                             |
| `.stat`         | Stat menüsü (sadece safe alanda)                                                                                                                                                           |
| `.sohret`       | Şöhret puanınızı (öldürme sayınızı) gösterir                                                                                                                                               |
| `.kontrol`      | Hedeflediğiniz oyuncunun statlarını, armorunu, guildini, fame/karma, kill/death, rütbe puanını ve stat veren özel eşyalarını gösterir                                                      |
| `.kredi`        | Online Kredi menüsü (sadece safe alanda)                                                                                                                                                   |
| `.armorduzenle` | Üzerinizdeki her şeyi çıkarır, binekten indirir ve armorunuzu sıfırlar. Armor değeriniz yanlış görünüyorsa kullanın, sonra eşyalarınızı tekrar giyin (sadece safe alanda, 10 saniyede bir) |
| `.yuzukcikar`   | Güç Yüzüğü'nü bırakır (sadece safe alanda)                                                                                                                                                 |
| `.afk`          | AFK (klavye başında değil) modunu açar/kapatır                                                                                                                                             |
| `.where`        | Bulunduğunuz yeri gösterir                                                                                                                                                                 |

## Bilgi ve menüler

| Komut                                             | Açıklama                                                                                               |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `.online`                                         | Oyundaki oyuncu sayısını yazar                                                                         |
| `.top10`, `.siralama`, `.istatistik`              | Sıralama menüsü                                                                                        |
| `.map`, `.harita`                                 | Harita: konumunuzu gösterir; buradan bir oyuncuya takip isteği gönderebilirsiniz (o oyuncu onaylamalı) |
| `.takipiptal`, `.gtakipiptal`, `.oksil`, `.arrow` | Takip okunu kapatır                                                                                    |
| `.depo`                                           | Eşya deposu (sadece safe alanda)                                                                       |
| `.spawntakip`                                     | Haritadaki aktif Random Spawn bineği sayısını yazar                                                    |
| `.stormpuzzle`                                    | Storm puzzle koleksiyon kitabını açar                                                                  |
| `.site`                                           | Web sitesini açar                                                                                      |
| `.ataturk`                                        | Türk bayrağı şiir penceresini açar                                                                     |

## Sohbet

| Komut                         | Açıklama                                                                   |
| ----------------------------- | -------------------------------------------------------------------------- |
| `.g <mesaj>`, `.gc <mesaj>`   | Guild sohbeti                                                              |
| `.ac <mesaj>`                 | Aile sohbeti                                                               |
| `.kufur`, `.ihbar`, `.bildir` | Küfür eden bir oyuncuyu bildirir (**Kurallar ve Cezalar** sayfasına bakın) |
| `.kralduyuru <mesaj>`         | Sadece PvP lig kralı: bütün sunucuya duyuru (30 dakikada bir)              |

| `.cure`, `.gcure`             | Zehirliyken Greater Cure potionunu içer                                             |
| `.ref`, `.refresh`, `.gref`   | Staminanız dolu değilse Total Refresh potionunu içer                                |
| `.agi`, `.gagi`               | Greater Agility potionunu içer                                                      |
| `.bleed`, `.gbleed`           | Kanamanız varsa Bleed potionunu içer                                                |
| `.halu`, `.halupot`, `.ghalu` | Hallucination etkisindeyken Hallucination potionunu içer                            |
| `.bandaj`                     | Bandaj kullanır                                                                     |
| `.inlor`                      | Night Sight (aydınlanma)                                                            |
| `.kralres`                    | Sadece PvP lig kralı: ölüyken kendini diriltir (30 dakikada bir, evde kullanılamaz) |

## Savaş

| Komut                | Açıklama                                                                                                                                                                            |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.poisur`            | Silaha zehir sürer: çantanızda Deadly Poison potion olmalı, silah çantanızda olmalı (kılıç, mızrak/kryss türü, balta ve dagger). 2 saniye sürer. Warrior'lar daha güçlü zehir sürer |
| `.silah`             | İki silah kısayolu kaydeder (hedefleyerek)                                                                                                                                          |
| `.silah1`, `.silah2` | Kayıtlı silahı kuşanır, kuşanmışsa çantaya indirir                                                                                                                                  |
| `.jewelery`          | Çantanızdaki takıları (Hits Talisman, Animal Shield, Stat Shirt, Stat Küpe, Mana Sandals) tek seferde giyer                                                                         |
| `.kupetak`           | Stat Küpe'yi takar                                                                                                                                                                  |
| `.talismanpower`     | Taktığınız sınıf talismanının özel gücünü kullanır (10 dakikada bir)                                                                                                                |
| `.cesetzaman`        | Ceset kesme özelliğinizin kalan süresini gösterir                                                                                                                                   |
| `.stun`              | Stun bonusunu açar/kapatır (Wrestling ve Anatomy 80 gerekir)                                                                                                                        |
| `.disarm`            | Disarm bonusunu açar/kapatır (Wrestling ve Arms Lore 80 gerekir)                                                                                                                    |
| `.ibranice`          | Sadece mage: büyü sözlerinizi rün harfleriyle gösterir, rakip hangi büyüyü attığınızı okuyamaz. Açar/kapatır, oyundan çıkınca kapanır                                               |
